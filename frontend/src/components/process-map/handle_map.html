使用说明

  • 上传PGM文件 - 仅支持P5格式的PGM文件
  • 钢笔工具 - 支持多边形和矩形选区
  • 画笔工具 - 使用黑色或白色画笔编辑图像
  • 箭头工具 - 添加标注箭头到图像
  • 拖拽模式 - 点击按钮进入拖拽模式，可自由移动图像
  • 任务模式 - 用红色矩形框选区域并添加到任务队列
  • 小手工具 - 点击任务区域按点击顺序排序
  • 缩放功能 - 使用缩放工具调整图像大小
  • 清除功能 - 完全恢复原始图像，移除所有编辑痕迹
  • 生成抠图 - 根据路径或编辑区域生成抠图
  • 任务队列 - 可拖拽排序任务，点击任务跳转到对应区域
