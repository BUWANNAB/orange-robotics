# 橙智控制台配色

统一主题：`frontend/src/modules/theme/console-theme.css`。
主要页面、登录、嵌入式定位/绑定和二维修图均加载同一主题。只调整颜色与控件视觉状态，不修改接口、权限、机器人状态或操作确认逻辑。

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 页面底色 | `#F3F5F8` | 浅灰蓝，区分页面与白色面板 |
| 面板 | `#FFFFFF` | 表格、表单、导航、弹窗 |
| 主要文字 | `#283B52` | 标题、正文与输入值 |
| 次要文字 | `#5F7085` | 帮助说明和状态描述 |
| 主操作 | `#3569B3` | 保存、发布、登录；悬停为 `#28568F` |
| 选中背景 | `#EAF1FB` | 当前菜单、页签和选中项 |
| 成功/启动 | `#257454` / `#EDF6F0` | 验证、启动、恢复与真实成功状态 |
| 停止/删除 | `#B54150` / `#FCF0F2` | 危险操作、失败；不把普通取消弹窗染成危险操作 |
| 注意 | `#86601D` / `#FAF4E7` | 重启、解除锁定和待确认事项 |
| 品牌 | `#C56A29` | 标识和少量品牌点缀 |

按钮含义始终由文字/图标与颜色共同表达。禁用按钮使用可读灰色，不保留启用时的成功/危险强调。悬停不能使停止或删除变成蓝色普通操作。

调度导航、资源分类和设备配置统一使用浅色。地图占用栅格、路线、坐标轴和雷达示意画布保持各自的数据表达，不通过统一主题重绘。

ROS 维护按钮通过 `data-ui-intent` 标注启动/停止/重启的配色语义；属性不改变允许操作和下发条件。

验证：原有 67 项前端测试；桌面七个页面与地图画布截图；手机/平板布局；菜单位置回归。抽样核对可用主按钮/导航入口/任务模式/地图验证按钮的文字对比度，最低 4.83:1，蓝底白字 5.49:1。该结果是抽样验证，不等于完整页面无障碍认证。

## 登录背景

登录页采用项目专用生成的明亮仓储 AGV 场景，文件为 `frontend/src/assets/backgrounds/orange-warehouse-login-v1.png`（约 1.6 MB），由本机服务分发，无外部图片请求。图中不包含文字或第三方品牌。

`login-background.css` 负责登录页独有的背景裁切与卡片处理：桌面居中，移动端偏左保留 AGV，浅色卡片承托表单，横屏短窗口允许正常滚动。图片加载失败时保留主题底色。移除了旧粒子动画，保留认证、提示和跳转逻辑。

核对 1920×1080、1440×900、900×720、390×844、844×390 五种尺寸；本地独立预览环境验证失败登录可返回表单，正确登录可进入系统。未连接机器人。
