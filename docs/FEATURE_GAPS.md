# 功能缺口与验收边界（2026-09-28）

依据当前代码和交付说明核查；十个管理模块已有基础链路，不代表原提示词包的每个扩展项均完成。

## 本次补齐

定位页面支持地图拖拽初始位姿：选择有底图的地图 → 拖拽重定位 → 按下选位置、拖出朝向 → 松开预览 → 点击右侧重定位按钮并确认。紫色箭头是待提交位置，松开不发送 ROS 指令。支持取消、Esc、手工修正坐标；短拖动拒绝产生朝向。地图工作台内嵌定位页面同步生效。仿真可预览但不可下发。

## 尚未实现或仅有部分链路

| 项目 | 当前边界 |
| --- | --- |
| 自动全局重定位 | 已补 FPFH/RANSAC + ICP 搜索、多帧验证与 NDT 接管；待 Linux/真实雷达验证，目前面向平面场景，不保证重复场景唯一定位。 |
| 地图坐标校准 | 已有可视化绑定界面；仍需人工核对两张地图的坐标原点、方向和米制单位，尚无自动配准工具。 |
| 路线高级编辑 | 支持直线路径；贝塞尔/圆弧、框选批量属性、图层锁定未实现。工作台支持 PGM/YAML，RDS 编辑器未自动导入整套资产。 |
| 运行线路显示 | 同屏显示本机桥接下发路线与路段进度；未显示其他 ROS 发布者路线、左右避障实际轨迹形状、多车统一实时叠加。 |
| 多车交通协调 | 有任务优先级与空闲车辆分配；未实现路段预约、路权互斥、交叉口协调、死锁解除。不能当作完整多车交通管制。 |
| 设备动作与业务联动 | 本机适配器支持导航/回充目标/软件锁；设备重启、硬件故障复位、设备端安全刷写未接入。到充电点不等于完成物理对接和充电握手。 |
| OTA | 平台上传、审核、编排、回执链路已有；真实设备下载/刷写/A-B 回滚、掉电恢复仍需设备端实现与验证。 |
| WMS | HMAC 推单、回调重试已有；拉取、消息队列、业务对账、双密钥过渡未实现。 |
| 报警与指标 | 没有可视化报警规则和第三方通知；SOH、剩余续航、里程、MTBF、利用率等缺少可靠采集/统计。 |
| 日志与部署 | 没有大规模异步导出中心；当前服务要求单 worker，多进程/分布式协同尚未支持。 |

## 已有代码，尚未完成现场验收

- Linux/ROS 编译：导航进度反馈、热切图/重定位、PCD 裁剪去噪 CLI、常驻雷达桥接和 systemd 模式切换。
- 真实雷达、TF、PLC、定位质量、停车回执、断流恢复和低速路线执行。
- 多台机器人适配部署、真实 WMS 对接、真实充电与设备 OTA。
- 生产 MySQL 迁移、权限配置、部署安全审查、长时间运行和目标规模压力测试。

优先顺序：Linux 编译与单机实车闭环 → 地图坐标核验与操作流程 → 多车路权 → 真实 WMS / OTA。当前 Windows 仿真与逻辑测试不代表接硬件即可投产。
