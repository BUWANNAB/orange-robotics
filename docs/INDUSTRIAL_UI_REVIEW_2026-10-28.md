# 工业操作流程检查与修复

日期：2026-10-28。范围：橙智本地源码、隔离数据库和本机浏览器预览。三组子智能体分别审查导航、配置维护、地图与任务流程，另有一组独立复核新增修复；主智能体整合、复现和验证。未连接或部署 021，也未向真实雷达、PLC 或底盘发操作请求。

## 本轮已修复

| 优先级 | 原问题及触发方式 | 修复后的行为 |
| --- | --- | --- |
| P1 | 运行中的单次任务不在最近六条记录中时，暂停/停止按钮消失 | 活动任务单独查询；历史分页不再决定是否有当前任务 |
| P1 | 选择历史任务链后，新活动链被历史详情挡住；活动链也可能被历史数量挤出 | 活动链单独查询，与历史去重；执行栏优先活动链，实际执行优先排队 |
| P1 | 旧地图保存请求尚未返回就切图，旧回执可能写进新地图上下文 | 保存绑定原编辑器、地图 ID 与 revision；迟到回执不污染新页面，同一编辑器串行保存 |
| P2 | 设备管理有时另开标签，有时内嵌；配置页右侧返回入口容易看不到 | 设备管理在当前工作区打开；全站顶栏始终有“返回地图主页”，雷达页标题下也有独立返回入口 |
| P2 | 返回时初始 URL 或最近资产可能覆盖实际正在编辑的地图 | 返回链接携带明确 mapId；工作区以当前选择为准，配置页保留显式深链上下文 |
| P2 | 雷达、模型与点云操作在切页/切工具时无提示丢修改 | 统一递归离开保护；放弃需确认，取消保持输入和面板 URL。点云面板收起只隐藏，保留未处理笔画 |
| P2 | 确认请求待回执时仍能关窗；旧请求会关闭后打开的其他窗口 | 提交期间锁定取消/关闭/Escape，并检查窗口身份；待提交操作阻止父级导航跳走 |
| P2 | 资源清单首次读取失败后，刷新变为“暂无地图”且不再读取 | 刷新重新获取清单和资源；可恢复错误，并保留同地图的筛选与选中状态 |
| P2 | 维护页读取失败后旧“就绪”状态与启动按钮仍可用 | 标记过期，启动和普通维护操作禁用，重新检查后恢复；独立软件停车请求保留 |
| P2 | 车体模型及权限读取失败时仍可提交保存，finally 还可能解除只读限制 | 默认禁用写入，读取与权限成功后再启用；失败可重读，保存失败保留修改 |
| P2 | 多台雷达扫描结果自动回填第一台；配置读取失败没有重试 | 多设备必须明确选择；失败显示“尚未读取”、禁用配置区并提供重读/返回，登录失效提供登录入口 |

独立复核还修正了三个边界：工作区切图后返回旧 query 地图、验证等待时仍可编辑导致回执覆盖输入，以及一秒离开许可跳过新出现的提交锁。短期许可仅用于避免重复的浏览器 beforeunload 确认，每一次导航仍重新检查当前状态。

## 主要实现位置

- `frontend/src/modules/navigation/navigation.js`：统一返回地图链接、递归子页面离开保护、当前地图上下文。
- `frontend/src/components/indoor-map/js/radar_drawer.js`：读取重试、未知配置门禁、未保存保护、多设备选择和提交期间冻结。
- `frontend/src/modules/operations/operations.js`：独立活动任务读取、执行栏优先级、保存与确认回执身份。
- `frontend/src/modules/maps/workbench.js`：点云选区/橡皮擦/原点参数的未处理保护。
- `frontend/src/modules/maps/resource-store.js`、`ros-maintenance.js`、`frontend/src/modules/robot-model/model.js`：失败恢复与过期/未读取状态控制。
- 后端只新增两个只读查询参数 `active_only=true`，分别用于任务历史与任务链列表；不改变设备执行协议和数据库结构。

## 验证证据

- 前端 Node 测试 **103 项通过**，包括新加入的工业流程、配置状态及跨 iframe 离开保护测试。
- 临时 SQLite 后端：运营 **28 项**、任务链 **16 项**通过。数据库与生产数据隔离。
- 浏览器工业交互 **6 条流程**通过：失败重试、返回同图、取消离开保留输入、多雷达显式选择、验证期间冻结与阻止跳页、同工作区往返及不同屏幕宽度。
- 原有地图/建图集成 **10 条流程**通过，包括登录恢复地图、模式写入与失败反馈、实时栅格展示、处理结果回到路线画布。
- 雷达扫描与验证均使用拦截的浏览器数据；未向实际后端发雷达配置写入。
- 页面脚本版本已更新，避免继续命中旧配置抽屉和导航缓存。

## 验证边界

这是已覆盖页面和故障路径的交互修复，不是全部工业功能或安全等级的验收。真实制动距离、定位精度、雷达发现与配置生效、PLC 使能和断网恢复，需要在设备上另行验证。浏览器原生离开提示由浏览器决定文本与显示条件；服务端回执、权限和停止检查仍是设备操作的最终条件。
