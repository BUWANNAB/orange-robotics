# RCS 手册主界面排版

本次对齐对象是《RCS 实施操作手册》的主界面、路线编辑和任务执行截图。主界面以手册 image9 / image20 的约 18.5% 左栏、63% 地图区、18.5% 右栏为基准；保留 Orange 品牌及已有建图、点云处理、路线发布、定位、任务链能力。

## 页面结构

- 顶部蓝灰导航：主页、运行管理、设备管理；手动/自动/调度置中，连接与定位状态置右。窄屏自动换行。
- 地图区顶部单排工具条：白色胶囊按钮、多色线性图标；文字保留在辅助名称和悬停提示。编辑、图层和更多工具可以展开。
- 左栏：地图选择、任务列表、可折叠单次任务、大车体状态示意、折叠站点与路线。
- 中间：白色地图，坐标网格极淡；右下悬浮平移、适应、放大、缩小和真实缩放百分比。
- 右栏：任务执行置顶，循环次数读取实际任务链；选择地图对象后展开属性，地图版本折叠在下方。
- 底部：地图区内一排定位、任务、PLC 和软件停止锁状态。未连接、未匹配地图和未知状态不显示为正常。
- 没有 PGM 时也保留上述工作台，中央提供已有 PGM 选择与实时建图入口，需要地图的编辑/发布工具禁用。

## 颜色

| 用途 | 色值 | 使用方式 |
| --- | --- | --- |
| 当前模式、主要确认 | `#015EE7` | 蓝色实心或选中边框 |
| 路线与站点 | `#1476FB` | 地图线条与普通站点 |
| 建图、地图处理 | `#1596A6` | 青色工具图标 |
| 站点及相关编辑 | `#8063CE` | 紫色工具图标 |
| 执行、继续 | `#28AE59` | 绿色动作 |
| 停止、删除、失败 | `#DF5266` | 红色危险操作 |
| 待确认、警示 | `#C89A32` | 琥珀色状态 |
| 面板、导航底色 | `#F0F2F7` / `#E2E7F1` | 与手册保持一致 |
| 品牌、坐标原点 | 橙色 | 保留 Orange 识别，不覆盖所有按钮 |

图标、文字、边框与禁用状态共同表达意义，不以颜色作为唯一提示。

## 行为边界与回归

工具和任务继续调用原接口及确认窗口。任务暂停仍表示到当前段到站后暂停后续步骤，不替代“停止并锁定”；顶部模式仍是任务链推进策略，不切换实体车辆驾驶模式。车体图是示意，不提供没有经过验证的方向遥控，也不显示虚构电量、续航或定位置信度。

“运行管理”导航在离开前保存当前草稿；保存失败留在原页面。缩放按钮与滚轮共用缩放范围，缩放时保持中心或鼠标对应的世界坐标不漂移。`zoomPercent()` 显示相对最近一次适应窗口的真实比例，适应后为 100%。

前端验证：`node --test frontend/test/*.test.cjs`。后端相关模块分别运行 `test_operations`、`test_missions`、`test_map_workbench`，不连接机器人。手册布局的 95% 是视觉验收目标，需要以同尺寸实际浏览器截图核对；代码检查和接口测试不能代替该项验收。
