# 地图工作台固定分区

地图操作使用固定分区，鼠标悬停不展开菜单，普通侧栏不使用遮罩或浮在地图上方。

- **上方**：全站导航、当前地图、任务模式、建图与地图工具、保存、校验和发布。
- **左侧**：全站功能栏；地图内侧栏直接显示地图编辑工具、图层、任务和对象列表，各栏独立滚动。
- **右侧**：任务执行、地图操作、对象属性和地图版本，默认可见。
- **下方**：地图平移/缩放/适应窗口和设备状态。视图按钮从画布内部移到独立工具行。

桌面的全站功能栏默认展开；操作员手动收起/展开后保留选择。切换页面不自动关闭。手机默认收起，手动展开后停靠在顶栏下方，内容区域下移；不用遮罩覆盖当前页面。小屏地图内部的左右栏按顺序排列到画布下方。

建图、裁切、二维地图编辑、自动重定位的设置作为工作台中的相邻区域。宽屏在右侧停靠，工作台可用宽度不超过 1280 px 时改为下方停靠。打开时地图让出空间，关闭时地图恢复占用空间。设置区是普通页面区域，不锁住地图的点击和键盘焦点；发布、重定位、继续行驶等关键操作原有确认弹窗保留。

画布观察实际尺寸变化：全图视图始终重新适应窗口；手动缩放或平移后，保持查看中心的世界坐标和相对于全图的缩放比例，同时根据新画布大小调整像素比例。暂时隐藏的画布忽略零尺寸变化。此过程不修改地图原点、站点、路线或机器人定位，也不保存地图草稿。

2026-10-28 本机验证：

- 前端 79 项测试通过，包括缩放中心、相对比例、非零地图原点、隐藏后恢复和固定工具布局。
- 浏览器核对 1920、1440、1280、900、390 px 宽度，页面无横向溢出；桌面上下左右区域不与画布重叠。
- 核对全站功能栏收起后地图扩大、展开后缩小；悬停不展开，键盘 Enter 可切换。
- 核对六个独立页面共用同一功能栏，建图设置占用相邻空间，无遮罩。
- 暂停/继续页面操作回归通过：暂停直接提交，继续保留确认，刷新保留暂停状态。
- 既有集成流程 10 项浏览器回归通过，包括登录地图恢复、模式切换及失败反馈、实时二维地图更新、处理完成回到路线画布。

验证使用隔离的本机预览和演示地图，没有连接或部署 021。
