# RDS 手册对照：导航与配置流程

参考：用户提供的《RDS 实施操作手册：库位系统下发任务》，26 页。
本轮范围是页面职责、统一导航和现有资源分类；没有实现整套仓储调度器，也没有改变机器人运行配置。

## 页面职责

全站入口共用 `frontend/src/config/sidebar.json`，由同一个导航组件分组。
所有主要页面的功能菜单固定在左上角，使用统一的 52 像素顶部导航，滚动和切页不改变位置。
首页内嵌页面共用首页顶部导航和抽屉；独立打开的页面展示相同位置、相同内容的菜单。
内嵌地图、编辑器和维护面板不重复生成入口。手机上的“运营分类”仅切换当前运营页面分类。
运营侧栏、地图对象栏、资源分类栏用于当前页面，不再承担全站跳转。

| 功能菜单分组 | 入口 | 页面内操作 |
| --- | --- | --- |
| 现场工作 | 地图与路线 | 实时建图、修图、原点、站点、路线、重定位、发布和任务执行 |
| 调度与运营 | 调度与运营 | 看板、机器人、电量、报警、任务历史、日志；系统配置折叠显示 |
| 地图与模板 | 地图资源 | 按当前地图整理站点、库位点、充电点、待命点、路线、区域、任务模板、文件、版本 |
| 设备与维护 | 雷达配置、车体坐标与模型、ROS 运行维护 | 各页只显示对应配置或维护操作 |

旧顶栏的轨迹录制、坐标、定位按钮只允许在旧版路线轨迹采集页显示，其他页面默认隐藏。
采用允许路径清单，新增页面不必逐个登记隐藏。它不是 LiDAR 实时建图的开始/保存操作。
地图创建已融合到地图与路线工作台的“实时建图”工具，不再保留独立侧栏入口。旧建图书签仍打开主地图和建图侧面板。

## 参考手册的操作顺序

手册第 6、9、11、14 节分别描述地图、库位、起终点规则和待命点配置。
橙智沿用同一张地图：选择地图 → 设置站点/库位位置 → 连通路线 → 保存任务模板 → 地图主页验证、发布、执行。
模板与执行记录分开；录制、地图编辑、设备配置不放在运营看板顶栏。

库位点、充电点和待命点是现有站点用途的分类视图，使用原有草稿保存、稳定标识与引用检查。
从分类中添加站点会默认相应用途；分类在刷新后保留，切地图只显示目标地图数据。
没有新增独立副本、第二套站点表或库存表，不需要数据库迁移。

## 能力边界

| 手册能力 | 当前状态 |
| --- | --- |
| 地图配置、站点、路线、任务模板、循环、执行记录 | 使用项目已有实现；本轮统一入口和分类 |
| 按库位、充电、待命用途查看/新增站点 | 已接入真实地图草稿 |
| 库区行列、库位规格、占用/空闲库存状态、进出规则 | 未实现，库位点不能视作完整库区系统 |
| 取货/放货映射、货叉升降、完成信号 | 未实现；继续遵守暂不添加货叉升降的要求 |
| 库位状态自动触发订单、任务类型匹配车辆 | 未实现；导航任务模板不能替代仓储业务规则 |
| 多车管制区、待命区优先级与自动回待命点 | 未完整实现；禁行/减速区和待命点标记不能替代交管/自动分配 |
| 充电位置标记与充电设备调度 | 标记已存在；自动充电仍取决于已有设备接口和现场反馈，标记不等于充电执行 |
| 手册的安装、防火墙、许可证和 AiTEN 私有格式 | 本轮不执行；仅参考流程，不导入专有格式 |

## 验证

- 前端 67 项测试通过，覆盖菜单来源/分组、录制显示边界及原有地图/任务行为。
- 本地独立预览环境：六个独立页面统一菜单、首页内嵌调度与维护、建图入口，共 11 项浏览器流程检查通过。
- 分类实际读取库位/充电/待命测试点，核对默认创建用途、刷新保留、模板入口。
- 运营原有 8 项浏览器流程和资源原有 14 项流程回归通过，包括删除再建同名站点、路线删除保留站点、任务引用阻止删除、双向地图链接。
- 运营 6 种尺寸、资源 5 种尺寸和功能菜单 3 种尺寸无页面横向溢出、无脚本异常。
- 使用本地独立测试数据库；未连接 021、未向车辆下发任务；实车建图与调度验收不在这些结果内。
- 固定导航补充验证：8 个主要入口 × 桌面/平板/手机 3 种尺寸，共 24 项位置与滚动检查通过；首页切到调度后入口不移动，嵌套页面只有一个全站入口，画布预留导航高度，无横向溢出或脚本异常。
