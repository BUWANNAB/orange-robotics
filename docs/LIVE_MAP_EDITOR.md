# 实时地图与线路编辑

入口：地图工作台右上角“实时地图 / 线路编辑”，或 `/ui/operations.html#maps`，选择地图并打开编辑器。

1. 用“添加点位”在地图上布点，用“连接路径”依次点击两个点。选择点位可拖动；选择路径可改方向、速度、宽度。
2. 保存草稿、校验、发布。草稿编辑不修改已下发的执行路线。
3. ROS_MAP_CATALOG 中的 PCD 必须绑定这张 RDS 地图的 map_id 和发布 version，在定位页面完成地图切换并收敛后显示实时车辆。
4. 同一画布叠加实测轨迹和已下发路线：蓝色为位姿采样轨迹；绿色为控制器已通过的完整路段；橙色为当前及剩余路段。当前路段不按位置插值拆分。
5. 紫色虚线表示没有可用进度或任务已取消/失败。断流超过两秒隐藏车位、清除轨迹，并停止显示实时进度；换图、定位失效同样清除轨迹。只显示本机 ROS 域对应车辆。

## 接口

继续使用鉴权 `/api/localization/ws`（10Hz）。navigation 增加 points（实际下发 9×N 数组中的 XY 快照）、map_id、version、key、target_index、progress_fresh。编辑草稿不影响该快照。

ROS `/navigation/result` String 新增 `任务ID\nprogress\n零基目标点索引`。C++ 控制器当前路段索引加一后发布；左右避障路径发布 -1，前端不推测避障路径形状或原路线进度。旧 ROS 节点不发送该消息时显示进度未知。桥接仅接收匹配当前 running 任务的反馈，并在两秒后判定过期；success 回执将全线标为完成。

## 验证边界

Windows 已验证前后端逻辑测试；ROS C++ 变更仍需 Linux 编译并在机器人上联调。当前 8097 为仿真预览，不提供真实运动验收证明。运行路线显示要求通过该桥接下发；无法观测其他独立 ROS 发布者私自下发的路线。
